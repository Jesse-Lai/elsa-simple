# prompt-kit

Chat Container, Message, Markdown, Code Block, Prompt Input, Prompt Suggestion, Scroll Button and Tool were sourced from the official registry on September 15, 2026.

Source: https://github.com/ibelick/prompt-kit
Registry: https://prompt-kit.com/c/registry.json
Upstream commit: de80375967400aa0c6ebab9d3ba4f9258ab79fcc

The application also uses the official prompt-kit light-theme color tokens from app/globals.css.

Local adaptations: IME-safe prompt submission; accessible hidden scroll button; safe code-highlighting fallback.
